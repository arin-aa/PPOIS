Detailed Description

Класс, представляющий персональный компьютер.

Хранит информацию о комплектующих (материнская плата, блок питания, накопители), позволяет собирать систему, устанавливать ОС и рассчитывать энергопотребление. Является базовым классом для Laptop, Server и Workstation.
