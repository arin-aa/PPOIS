Detailed Description

template<typename T, typename Compare = std::less<T>>
class Sorter< T, Compare >

Abstract base class for sorting algorithms.

Provides a common interface for sorting a std::vector or a plain array. A concrete algorithm only has to implement sortRange().

Template Parameters
TElement type.
CompareComparator type. Must return true if the first argument should go before the second one. Defaults to std::less<T>.
