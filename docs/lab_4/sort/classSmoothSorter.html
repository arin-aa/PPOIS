Detailed Description

template<typename T, typename Compare = std::less<T>>
class SmoothSorter< T, Compare >

Smoothsort by Dijkstra.

Worst case O(n log n), O(n) on nearly sorted data, O(1) additional memory (not counting the forest of O(log n) trees).

The array is treated as a forest of Leonardo heap trees whose orders decrease from left to right. A tree of order k occupies L[k] elements:

[ left subtree of order k-1 ][ right subtree of order k-2 ][ root ]

Forest roots are in ascending order, so the last root is the maximum.

Leonardo numbers: L[0] = L[1] = 1, L[k] = L[k-1] + L[k-2] + 1.
