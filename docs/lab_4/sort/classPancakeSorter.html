Detailed Description

template<typename T, typename Compare = std::less<T>>
class PancakeSorter< T, Compare >

Simple pancake sort.

For each shrinking prefix the maximum is found, flipped to the front (reversing the prefix that ends at the maximum) and then flipped to the end of the current prefix. O(n^2) comparisons, O(1) additional memory. The sort is not stable.
