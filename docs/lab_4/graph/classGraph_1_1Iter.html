Detailed Description

template<typename T>
template<IterKind K, bool C, bool R>
class Graph< T >::Iter< K, C, R >

Graph iterator template.

Bidirectional graph iterator.

Template Parameters
KIterator kind.
Ctrue for a constant iterator.
Rtrue for a reverse iterator.

A single template describes all 16 iterators: over vertices, edges, incident edges and adjacent vertices, in forward and reverse variants, constant and non-constant. The vertex iterator returns a vertex value, the edge and incident edge iterators return a std::pair of endpoint values, and the adjacent vertex iterator returns the value of the neighbouring vertex. A reverse iterator stores a position one element past the current one.

Template Parameters
KIterator kind (IterKind).
Ctrue for a constant iterator.
Rtrue for a reverse iterator.
