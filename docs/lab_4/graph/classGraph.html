Detailed Description

template<typename T>
class Graph< T >

Undirected graph (modified Wirth structure).

Vertices are stored in a list of smart pointers, and each vertex keeps a list of its incident edges. An edge holds weak pointers to its endpoints. Duplicate vertices, parallel edges and loops are forbidden.

Vertices are stored in a list of smart pointers, and each vertex keeps a list of its incident edges. An edge holds weak pointers to its endpoints. Duplicate vertices and parallel edges are forbidden, loops are allowed. The class supports adding and removing vertices and edges, checking for their presence, computing vertex and edge degrees, and forward, reverse and constant iterators over vertices, edges, incident edges and adjacent vertices.
