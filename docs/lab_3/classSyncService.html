long long SyncService::sync ( const std::string & entityType,
long long localVersion,
const std::string & strategy )

Synchronizes one kind of data with the cloud.

Missing data is uploaded. If the versions differ, the conflict is resolved by the strategy and the cloud is updated when it does not hold the winning version.

Parameters
entityTypeKind of data.
localVersionVersion stored on the device (ms).
strategy"local", "remote" or "newest".
Returns
Version that is stored on both sides after the synchronization.
Exceptions
SyncExceptionif the cloud rejects the request or the strategy is unknown.
